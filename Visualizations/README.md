# Matplotlib and Seaborn Learning Notes

## Matplotlib

I learned how to create and customize common charts using Matplotlib, including:

- Line charts
- Bar charts
- Pie charts
- Histograms
- Scatter plots
- Multiple lines and legends
- Titles, axis labels, colors, markers, line styles, grids, and transparency

I also learned how to use `matplotlib.pyplot` and improve charts so they are clear and easy to understand.

## Seaborn

I learned how to create statistical visualizations using Seaborn and Pandas DataFrames, including:

- Scatter plots
- Line plots
- Bar plots
- Count plots
- Histograms
- Box plots
- Heatmaps
- Pair plots

I practiced using `data`, `x`, `y`, and `hue`, loading Seaborn datasets, inspecting data with Pandas, applying themes, and customizing charts.

## Key Takeaway

Matplotlib gives detailed control over visualizations, while Seaborn makes statistical charts faster and easier to create. Both libraries help me explore data and communicate insights clearly.
