# Python Practice

This folder contains Python learning exercises, practice files, and short projects used during my journey to become a data analyst.

## Purpose

Use this directory to:
- Practice Python basics and intermediate concepts
- Try small coding exercises and hands-on problems
- Experiment with functions, loops, data structures, and file handling
- Build confidence with Python for data analytics workflows

## What I learned

Below is a summary of the concepts, techniques, and tools I practiced while working through the notebooks and scripts in this folder.

Core Python fundamentals
- Variables and basic data types (int, float, str, bool)
- Type conversion and formatting
- Basic I/O: reading from and writing to files (text and CSV)

Control flow & structure
- Conditional statements: if / elif / else
- Looping: for and while loops
- Comprehensions: list, dict, and set comprehensions

Functions & modular code
- Defining and calling functions, default and keyword arguments
- Return values and multiple returns
- Structuring code into modules and reusing functions

Data structures
- Built-in collections: lists, tuples, sets, dictionaries
- When to use each collection type
- Basic operations: indexing, slicing, add/remove, iteration

Error handling & testing
- Exception handling with try / except / finally
- Basic debugging techniques (print/debugger)
- Writing simple assertions for quick checks

Working with data
- Using the csv module for simple CSV reading/writing
- Basic text parsing and string methods
- Introduction to using pandas (if included in notebooks) for tabular data handling

File handling & scripts
- Reading/writing files using context managers (`with` statement)
- Organizing script entry points (`if __name__ == "__main__":`)
- Small command-line argument parsing (argparse) — practiced in simple scripts

Intermediate techniques
- Itertools and collections (where used)
- Lambda functions and higher-order functions (map/filter/reduce)
- Debugging and profiling small code snippets

Project-based practice
- Short practice projects: small calculators, text processors, CSV summarizers
- Mini data cleaning exercises: handling missing values, type conversions, normalization
- Exploratory data analysis (EDA) examples in notebooks: summary statistics, simple plots

Good habits developed
- Writing readable, well-commented code
- Incremental testing while developing functions
- Keeping notebooks and scripts focused on a single task
