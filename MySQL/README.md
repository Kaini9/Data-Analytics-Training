# MySQL

This folder contains MySQL practice exercises and assignments completed as part of the **Data Analytics Training** journey at Mindriser's Institute of Technology.

The materials focus on building a strong foundation in SQL and relational database concepts, including database creation, data manipulation, filtering, keys, and table relationships.

## Folder Structure

### `Practice/`

Hands-on SQL exercises and tutorials covering introductory querying and data analysis concepts:

- Creating and working with databases and tables
- Using `SELECT` statements
- Filtering records with `WHERE`
- Applying logical operators
- Pattern matching with `LIKE`
- Practicing with the Parks and Recreation sample database
- Introductory data analytics queries

### `Assignments/`

SQL assignments and reference materials covering:

- `CREATE`, `INSERT`, `UPDATE`, and `DELETE` statements
- Primary keys and foreign keys
- Relationships between tables
- Relational database practice questions
- SQL practice assignments in PDF format

## Topics Covered

- Database and table creation
- Data types and table structure
- Inserting, updating, and deleting records
- Retrieving data with `SELECT`
- Filtering and sorting query results
- Logical operators such as `AND`, `OR`, and `NOT`
- Pattern matching with `LIKE`
- Primary keys and foreign keys
- Basic relational database design

## Getting Started

1. Install [MySQL Community Server](https://dev.mysql.com/downloads/mysql/) and a MySQL client such as MySQL Workbench.
2. Open a `.sql` file from the `Practice` or `Assignments` folder.
3. Connect to your MySQL server.
4. Run the statements in sequence, especially files that create databases or tables.
5. Modify the queries and experiment with different conditions to reinforce the concepts.

> **Tip:** Always review the database and table names used in a script before executing it. Some exercises may create or modify data in your local MySQL environment.

## Learning Goals

By completing the exercises in this folder, you should be able to:

- Create and manage basic MySQL databases and tables.
- Perform CRUD operations on relational data.
- Write queries to retrieve and filter records.
- Understand the purpose of primary and foreign keys.
- Establish relationships between database tables.
- Apply foundational SQL skills to data analytics tasks.
