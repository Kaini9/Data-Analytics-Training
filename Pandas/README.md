# Pandas Practice

This folder contains my Pandas practice notebooks and exercises completed during my journey toward becoming a data analyst.

## Practice with the Titanic Dataset

During guided practice, I worked with the Titanic dataset to learn how to inspect, clean, transform, and analyze real-world data using Pandas. The main activities included:

- Loading the Titanic dataset into a Pandas DataFrame.
- Exploring the structure of the dataset using methods such as `head()`, `tail()`, `info()`, `describe()`, and `shape`.
- Checking column names, data types, and unique values.
- Identifying and handling missing values, especially in columns such as `Age`, `Cabin`, and `Embarked`.
- Filtering rows based on conditions such as passenger class, gender, age, and survival status.
- Selecting and renaming columns for clearer analysis.
- Sorting records and creating meaningful subsets of the data.
- Grouping data by categories such as passenger class and gender.
- Using aggregation functions including `count()`, `sum()`, `mean()`, `min()`, and `max()`.
- Comparing survival rates across different passenger groups.
- Creating new columns and using conditional logic to support analysis.
- Working with indexes and resetting indexes when needed.
- Drawing insights from the dataset through summary tables and comparisons.
